# Contributing to Instana OpenTelemetry Go Contrib

> [!IMPORTANT]
> This is a private fork maintained by IBM Instana and is currently in active development. We are not accepting external contributions at this time. This document serves as internal development guidelines for the Instana team.

This project is based on the open source [OpenTelemetry Go Contrib](https://github.com/open-telemetry/opentelemetry-go-contrib) implementation and follows the [OpenTelemetry Specification](https://opentelemetry.io/docs/specs/otel).
